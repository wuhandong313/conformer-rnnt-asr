## 算术定义

一 MAC 指一次乘加；整集指标为 `sum(utterance MACs) / sum(actual FLAC seconds) / 1e9`。包含线性、卷积、两个注意力矩阵乘法、输入输出投影、融合 MLP、相邻余弦的点积部分、五帧加权和、实际搜索展开的 predictor 门与投影及 joiner 投影。未计特征提取、归一化、softmax、激活、峰谷比较、top-k、排序、访存与 Python 控制流。

单层 Conformer 的主要 MAC 为 $T(4DF+7D^2+Dk)+2DT^2$，其中 T 为该层实际有效长度，D 为主干宽度，F 为 FFN 宽度，k 为深度卷积核长度。融合 MLP 为 $K(5D\cdot32+32\cdot5)$，相邻点积为 $(T-1)D$，加权和为 $5KD$；单帧旁路按实际执行处理。predictor 与 joiner 按真实调用的行数统计，不用参考转写长度代替搜索路径。

## 计算预算与后续实验

E06 相对 E05 的合计主要 MAC 降低 74.92%；E03 使用 E05 的 67.44%，观察到的 PER 低 0.962 个百分点。E02→E06 合计进一步降低 39.14%，PER 增加 0.110 个百分点。以上均为固定 checkpoint 的探索性 test-clean 系统结果，独立质量门槛与池化训练仍待完成。
