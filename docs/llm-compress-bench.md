# LLM token 压缩实验：compression.py 方法族 × Qwen3.5-0.8B

> 分支 `llm-compression` | 2026-09-21 | 代码 `llm_compress.py`+`scripts/bench_compress.py` | 数据 `bench_compress_results.csv`(121 行)

## 1. 压缩方式介绍

**插入机制**（钩子方案，不改 transformers 源码）：压缩作用于**第一个 full_attention 层（idx 3）的输出**——
layer3 post-hook 对 hidden (B,L,1024) 执行选择/混合，并 `index_select` 裁剪该层 KV 缓存（`Cache.get_seq_length` 恰读该层，decode 位置自动连续重锚）；layer4+ pre-hook 将 cos/sin 按 keep 索引切片。B=1、L≤64 或解码步（L==1）整链透传。

**与原程序（`compression.py`）的模式对应**——同一管线：帧差信号 → (可选滤波) → 峰谷检测 → (可选 Hanning 窗混合) → 尾部直通区：

| 模式 | 信号处理 | 选择 | 混合 | 迁移适配点 |
|---|---|---|---|---|
| `none` | 旁路基线 | — | — | — |
| `naive` | 原始帧差 sum\|Δh\| | find_peaks 峰∪谷 | 无 | 逐字对齐 |
| `hanning` | 同上 | 同上 | Hanning 窗加权 | **可学习 weight predictor 无 LLM 训练来源 → 标准 Hanning 系数替代** |
| `fir` | FIR 低通粗检→原始±2 精修 | 精修后峰∪谷 | 无 | ASR 200Hz/50Hz 截止 = 归一化 1/2 Nyquist，token 域直接取 0.5 |
| `fir_hanning` | 同 fir | 同 fir | Hanning 窗 | 同上两条 |
| `savgol` | Savitzky-Golay(w≤9,4阶) 平滑 | find_peaks | 无 | 逐字对齐 |
| `savgol_hanning` | 同 savgol | 同 savgol | Hanning 窗 | 同 hanning |

**推广/对照族（非 compression.py 原生，本实验的坐标系）**：
`diffq_50/_85`=帧差幅值分位阈值（自适应 prominence 的保序推广，keep_frac 直控压缩率——原法族保留率被极值密度锁死在 ~31-45%，无温和压缩工作点）；`novelty_50`=局部窗口最近邻距离（检验"换信号"能否救峰谷框架）；`random_50`=同保留率随机子集（无信息下界）。`keep_last=16` 对应原程序 right_context（decode 场景改为强制保留尾部），min_len=64。
