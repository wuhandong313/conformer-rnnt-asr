## 2. 当前不能作出的推断

- 第5层方案前五层处理完整序列，且最终帧多于stride4基线。更好的PER尚不能证明更低计算量。
- 第2层与Mel的预算6500，第5层5000；现有配置使用sum RNNT loss、按步warmup和按步验证。不同批次意味着更新数、warmup覆盖数据、梯度尺度和选模机会不同。同维度、同epoch不等于完全受控。
- 原四组在GPU解码，位置实验在CPU解码。正式比较应固定设备/数值设置，或先完成跨设备预测一致性检查。峰谷离散决策可能受浮点差异影响。
- 各单次动态阶段的平均保留率都约40%。这既不能证明它只是固定比例，也不能证明它已按语言信息密度有效分配计算。需要逐句与负对照证据。
- 当前test-clean已经用于多次探索；后续方法选择在dev完成，新增独立测试仅用于确认。

## 3. 第一阶段：利用已有模型补齐证据

1. 等layer7结束并以同一协议评测；保留Mel/2/5/7及2+5完整结果，避免继续无目的扩大层号网格。
2. 用当前模型重新整理十档语速、S/D/I及候选间距、覆盖范围和融合权重分布。旧作废方法的十档结果不能沿用。
3. 对主要比较做按speaker的配对cluster bootstrap，报告corpus PER差值与区间。它刻画测试抽样不确定性，不刻画训练seed方差。
4. 同句保音高变速（建议先在dev验证0.8、1.0、1.2、1.4倍），观察删除错误与实际保留率，不只按不同句子相关性解释语速效应。
5. 检查同一句在不同拼批下的有效输出，以及CPU/GPU数值一致性；作为机制分析的有效性门槛，发现问题另行审批，不偷偷修正并混用结果。

## 4. 第二阶段：优先补最有辨别力的对照

以开发集决定的层位为主；当前第5层是优先候选，不能因test最优就把它视为已完成独立选模。保持同一主干、数据、层位、tokenizer与解码。

| 对照 | 回答的问题 |
|---|---|
| 均匀中心 + five_frames | 收益来自自然峰谷位置，还是后移降采样加可学习局部融合？ |
| 自然峰谷 + 五帧等权平均 | 输入条件权重预测是否有必要？ |
| 均匀中心 + 五帧等权平均 | 补全位置×融合的2×2对照，判断组合效应 |
| stride1完全不压缩 | 保持高分辨率本身能达到怎样的精度和成本？这是参照，不是理论精度上界 |
| A-ToMe适配同一Conformer-RNN-T | 相比已有相邻合并方法是否仍有实际价值？ |

正式确认采用共同有效批次、样本顺序、增强随机流、更新和验证日程。当前方法也要在该协议下确认；若报告相对stride4的受控提升，stride4同样需要该协议下的对照。历史七组保留为探索结果，原文件不覆盖。

预算有限时，先做“均匀+five_frames”“峰谷+mean5”和本方法的共同协议确认，再做A-ToMe；其余行依前述结果决定。

长度控制分清两个层次：
- 诊断：同一冻结表示、同一句保持自然K不变，只换均匀/随机位置。推理替换有分布偏移，只能作敏感性证据；若训练下游，所有行共享冻结前缀才能保持共同的K和表示。
- 系统比较：均匀采样率和A-ToMe阈值只在dev校准，覆盖主方法附近的实际计算开销，再训练/测评完整系统。不能把不同端到端模型各自产生的K称作逐句严格匹配。

对照的固定比例不进入主方法；主方法继续无目标保留率。A-ToMe原论文每次相邻合并有自身约束，不应为了匹配39%输出比例随意改算法；必要时保留多次合并，并如实说明与单次第5层方案的拓扑差异。在同骨干上的适配要标明，不声称复现原论文不同规模模型的绝对成绩。

若自然位置、条件融合都胜过简单对照，再考虑峰-only、谷-only、峰谷联合和全局固定可学五权重。需要控制实际长度，避免把少帧误差当作峰/谷机制差异。

## 5. 效率与自适应机制

若论文主张高效压缩，需在同设备、dtype、线程和解码设置下测编码器毫秒数、端到端时延、显存和FLOPs。可不把RTF作为主表指标。保留率不是速度；检测、CPU同步、融合和打包开销全部计入。至少比较stride4基线、Mel、第5层、最终选定方案及强基线，batch1和吞吐分别报告。

自然长度的作用需要与“位置作用”区分。分析每句K/T、K/秒、参考phone密度；控制时长、speaker及噪声。用相近时长组内打乱K/T、随机距离曲线等负对照，检验是否主要反映局部振荡。参考标签/强制对齐只能用于分析，不能成为部署时的选点输入。

多层方案第一阶段实际只减少13.92%帧，第二阶段保留41.86%。应画每层有效长度及候选在原时间轴上的覆盖，确认前段节省是否足以补偿误差增加。不得直接把最终36.03%当作所有层的计算比例。

## 6. 中文和外部确认

中文作为已选研究假设的跨语言验证。待用户允许数据准备后，两组共享冻结的AISHELL-3/THCHS-30标签、批次和归一化；在英文dev上确定动态层位，再用于中文，避免每个测试集都重新选最好层。

报告AISHELL-3和THCHS-30各自音节错误率、S/D/I和语速分析，再给合并值。联合训练的两个测试集不等于两套独立训练重复；英语音素PER与中文音节错误率也不能直接平均成一个分数。

如可获得一致且审计通过的phone69参考，test-other可作为困难条件的额外确认。未验证标签或数据时不填入结果、不自动下载。

遵守本轮范围：多seed、BPE/WER、另一主干不列为必做。论文结论相应限定为音素/音节识别与当前架构，不能声称词级ASR、跨架构或跨训练初始化普遍成立。

## 7. 文献与投稿判断

- [A-ToMe，Interspeech 2023](https://www.isca-archive.org/interspeech_2023/li23i_interspeech.pdf)：相邻token合并，包含固定比例与固定阈值；仅强调动态长度或不设固定比例不足以建立新颖性。
- [Towards Audio Token Compression，2026-08版本预印本](https://arxiv.org/html/2511.20973v2)：已比较相邻特征变化的峰值分段、均匀采样和平均池化。任务是LALM，应对照其思想而非照搬绝对指标。
- [AdaTS，ICLR 2026，作者机构条目](https://www.it.pt/Publications/PaperConference/41879)：在SLM中研究自适应采样与多任务效果，说明该方向有价值，也提高了“仅动态压缩”的新颖性门槛。不要求本项目为比较而另训练SLM。
- [CTC-guided RNN-T](https://arxiv.org/abs/2210.16481)：辅助CTC指导中间帧裁减。若主张无额外边界监督，应讨论与该类方法的监督、参数和成本差异。
- [ICLR 2027评审指南](https://www.iclr.cc/Conferences/2027/ReviewerGuidelines)：主张与证据、新知识和意义是重点；不要求所有工作必须SOTA，也没有“跑够若干实验即能录取”的规则。

当前最有希望的研究问题：自然极值选帧与条件局部融合如何随表示深度共同影响识别信息保留、时间分辨率和计算开销？

决策规则：若均匀+five_frames达到相同表现，则削弱峰谷创新主张；若mean5相当，则条件权重网络不是已证实的必要成分；若只靠更多未压缩层获得低PER而开销不占优，则定位为质量/表示机制研究；若严格对照和中文确认都支持优势，再组织无目标率压缩的算法与机制贡献。任何一个负结果都保留，避免只挑最好配置。

建议顺序：完成layer7并统一已有结果 → 现有模型误差/语速/开销分析 → 共同协议下的简单对照和A-ToMe → 冻结方法后开展中文确认 → 根据实际发现确定论文主张与投稿方向。
