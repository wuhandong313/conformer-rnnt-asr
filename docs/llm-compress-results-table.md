# 压缩方法 × 测试 prompt × 结果对照表

> 环境：Qwen3.5-0.8B 本地 fp32/MPS，贪心解码，max_new=32，chat template 与 infer.py 同路径。
> 插入点：**第一个 full_attention 层（idx 3）输出后**。数据源 `bench_compress_results.csv`（88 行全量），生成日期 2026-09-21。

## 1. 方法族说明

| 配置 | 归属 | 显著性信号 | 选择方式 | 压缩率旋钮 |
|---|---|---|---|---|
| savgol_d2 / savgol_d4 | **compression.py 原法** | savgol 平滑的相邻帧差 sum\|Δh\| | find_peaks 峰∪谷 (+首+尾K) | distance（实测饱和 ~41% 保留） |
| savgol_hanning_d2 | **compression.py 原法+混合** | 同上 | 同上，kept 帧做固定 Hanning 窗加权平均（被丢 token 信息折叠进邻帧；替代未训练的 weight predictor） | distance |
| diffq_50 / diffq_85 | 原法的保序推广 | 帧差 s_i=max(diff前后邻) | 分位数阈值（自适应 prominence），keep_frac 直控压缩率 | keep_frac |
| novelty_50 | 对照消融 | 局部窗口最近邻距离 | 分位数阈值 | keep_frac |
| random_50 | 下界对照 | — | 随机子集（同保留率） | keep_frac |

## 6. 读表要点

- **原法族 vs 分位推广**：同看 N3"冬至"——savgol 三配置全灭（碎片化后模型转向幻觉归纳句式），diffq_50 命中、diffq_85 四条 gist 全对——帧差信号可用，但"局部极值"式用法在 LM 上不可用，"按幅值排序"式勉强可用。
- **85% 保留仍碎日期**（N0 diffq_85 → "3 月 1"）：数字 token 在档案平滑句式里帧差最低，被分位阈值**优先**丢弃——负证"帧差低≠不重要"。
- **Hanning 混合无救反害**：与 savgol_d2 同 keep 集（218/636），答案 "2020年10月17日"(碰对17) → "2023年3月27日"——窗内平均把数字糊进邻居。
- **savgol_d4 的 gist 0/4 输给随机**：峰谷检测系统性保留 filler 句界、丢弃句内重复核心——原法在冗余文本上是**反向选择**。
- novelty 组证明窗口几何统计同属失败家族；random_50 给出同保留率下界，各配置与它持平即无信息量。
